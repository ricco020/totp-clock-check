# TOTP Clock Check

Browser-only tool: measures device clock drift against the server `Date` header and generates RFC 6238 TOTP codes with the Web Crypto API. Includes a self-test on the RFC 6238 appendix B vectors. No secret leaves the page.

Live: https://ricco020.github.io/totp-clock-check/

Background on choosing an authenticator app (backup, sync, open source): https://www.pwdfortress.com/en/blog/best-authenticator-app-2fa-2026
